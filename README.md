# 🔧 GK Bike Service Management System

A desktop application developed to manage day-to-day operations of a bike service center, including customer records, bike details, job cards, spare parts, inventory, billing, and reports.

## 🚀 Features

- Customer and bike management
- Service job card creation and tracking
- Mechanic assignment
- Spare parts and inventory management
- Stock updates for parts issued and returned
- Billing and payment tracking
- Service history and reports
- Role-based access for Admin and Service Advisor

## 🛠️ Tech Stack

**Application**
- Java
- JavaFX
- FXML
- CSS

**Database**
- PostgreSQL
- JDBC

**Build Tool**
- Maven

**Development Tools**
- NetBeans
- Scene Builder
- Git & GitHub

## 🏗️ Application Overview

The application is designed to help a bike service center organize customer information, service operations, inventory, and billing in one desktop system.

## ▶️ Getting Started

1. Clone this repository.
2. Install a compatible JDK and PostgreSQL.
3. Configure the database connection for your environment.
4. Create or configure the required database schema.
5. Open the Maven project in NetBeans or another compatible IDE.
6. Build and run the application.

**Note:** Database setup and login credentials depend on the local configuration. Do not publish real passwords or sensitive credentials.
